Preface

Preface

At MIT, there is an excellent course on operating systems that I'd like to share with you. Its approach combines theory and practice in a remarkably effective way.

  • The practical part is built around xv6, an educational operating system written in C that implements all the core concepts of modern OS design. In many ways, it resembles early versions of Linux.
  • The theoretical part is covered in a detailed guide to operating systems in general and xv6 in particular.

Both the code and the guide are freely available under one of the most permissive licenses — the MIT License. On the one hand, this makes it an outstanding resource for self-study; on the other, the learning curve is quite steep because the guide doesn't explain how to build, run, or debug the OS. That's understandable — the text was created as lecture material for MIT professors, not as a standalone textbook.

My goal is to adapt this material for independent learners. To make that possible, I've filled in the gaps in the original guide, added missing chapters, and expanded existing ones. I've also integrated a build and debugging environment for xv6, which can be run inside a Docker container. This setup has been tested on Ubuntu 24.04, Debian 13, Fedora 42, macOS 15.1, and Windows 11.

Who This Book Is For

This book is primarily intended for:

  • students and instructors of operating systems courses in universities and technical colleges;
  • systems programmers who want to gain a practical understanding of how Unix-like operating systems work to write more informed code;
  • aspiring kernel hackers eager to contribute to Linux or any other OS kernel.

You're expected to have some experience with C programming, to work in (or at least be familiar with) a Unix-like system or WSL2, and to feel comfortable using the command line. Familiarity with Docker and Git is also assumed.
